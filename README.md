# 🔑 Gerador de Senhas Seguras

Um aplicativo web simples, moderno e eficiente para a geração de senhas aleatórias e personalizáveis, desenvolvido com tecnologias fundamentais da web (**HTML**, **CSS** e **JavaScript**).

---

## 🚀 Funcionalidades

- 🎲 **Geração Aleatória:** Cria senhas fortes e únicas instantaneamente.
- ⚙️ **Personalização:** Escolha o tamanho da senha (de 6 a 32 caracteres).
- 🔣 **Filtros de Caracteres:** Inclua ou exclua:
  - Letras Maiúsculas (`A-Z`)
  - Letras Minúsculas (`a-z`)
  - Números (`0-9`)
  - Símbolos Especiais (`!@#$%^&*...`)
- 📋 **Cópia Rápida:** Botão para copiar a senha gerada para a área de transferência com um clique.
- 📱 **Design Responsivo:** Interface escura e moderna que se adapta a ecrãs de computadores e telemóveis.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do projeto.
- **CSS3:** Estilização moderna utilizando Flexbox e variáveis visuais.
- **JavaScript (ES6):** Lógica de manipulação do DOM e geração aleatória de caracteres.
