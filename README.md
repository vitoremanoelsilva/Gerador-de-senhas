Funcionalidades :
​Ajuste de Comprimento: Escolha senhas entre 6 e 32 caracteres.
​Filtros Personalizados: Opção de incluir/excluir:
​Letras Maiúsculas (A-Z)
​Letras Minúsculas (a-z)
​Números (0-9)
​Caracteres Especiais/Símbolos (!@#$%...)
​Cópia Rápida: Botão para copiar a senha direto para a área de transferência.
​Layout Responsivo: Interface moderna e adaptada para dispositivos móveis e desktop.

​🛠️ Tecnologias Utilizadas
​HTML5: Estruturação dos elementos.
​CSS3: Estilização responsiva e tema escuro (Dark Mode).
​JavaScript (Vanilla): Lógica de geração aleatória e manipulação da área de transferência.
